# Astro Version

This folder contains an Astro version of the current locksmith site.

## Run

1. Install Node.js 20+
2. Run:

```bash
npm install
npm run dev
```

## Included pages

- `/`
- `/electronic-page/`
- `/product/[id]/`

The Astro project keeps its electronic product data in `src/lib/legacy-product-data.js`.
